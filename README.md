# MeasureCam · 相机测量 App（Web/PWA）

用手机摄像头**测量物体长度与面积**的 PWA 应用。可添加到主屏幕当 App 使用，支持离线。

## 两种测量模式

| 模式 | 原理 | 精度 | 适用 |
|------|------|------|------|
| **AR 测量** | WebXR `immersive-ar`，利用 ARCore 实时位姿 + 命中测试放置真实世界锚点 | 较高（厘米级） | 支持 ARCore 的安卓 Chrome |
| **估算测量** | 设备方向传感器 + 相机高度/视场角，把屏幕像素反投影到地面平面 | 中（估算） | iOS / 桌面 / 所有带方向传感器的设备 |

## 功能

- **长度测量**：点按屏幕放 2 个点，实时显示两点距离
- **面积测量**：依次放置 ≥3 个点构成多边形，实时显示面积
- **单位切换**：cm / m / in / ft（面积对应 cm² / m² / in² / ft²）
- **已知长度校准**（估算模式）：用一把已知长度的直尺/银行卡（85.6mm），测完点两端后输入真实长度，自动修正视场角，显著提升精度
- **参数校准**：相机高度（默认 1.6m）、镜头垂直视场角（默认 60°）可调
- **历史记录**：测量结果本地保存（localStorage），可删除
- **撤销 / 清除**：误点可回退

## 运行方式

项目根目录在 `measure-cam/`。浏览器直接 `file://` 打开拿不到摄像头，必须通过 HTTP 服务访问。

### 本机测试
```bash
cd measure-cam
python -m http.server 8123
# 打开 http://127.0.0.1:8123/index.html
```

### 手机真机使用（同一局域网）
1. 电脑启动上面的服务器；
2. 查电脑局域网 IP（如 `192.168.1.5`）；
3. 手机连同一 Wi-Fi，浏览器打开 `http://192.168.1.5:8123/index.html`；
4. 授予摄像头权限；Chrome 菜单「添加到主屏幕」即可当 App 使用。

> 摄像头接口（getUserMedia）要求 HTTPS 或 localhost。局域网 IP 访问在 Android Chrome / iOS 上通常被当作不安全的"非本地"来源而受限。**推荐**部署到任意 HTTPS 静态托管（如 GitHub Pages、Vercel、Netlify、Cloudflare Pages）以获得完整能力。

### 部署（HTTPS，推荐）
把 `measure-cam/` 整个目录推送到任一静态托管即可，无需构建。Service Worker 会自动缓存实现离线可用。

## 使用步骤（估算模式，推荐先校准）

1. 选「估算测量」→ 开始；
2. 打开「校准」，确认相机离地高度与你手持高度一致（可调）；
3. 地面放一把直尺（或银行卡），切到「测长度」，沿尺子两端各点一下；
4. 点「校准」→「用最后两点校准」，输入真实长度（银行卡长 0.0856m）→ 自动修正视场角；
5. 之后测任意物体：长度点两端、面积依次点各顶点。

## 精度说明与限制

- **AR 模式**：依赖设备 ARCore 位姿，被测物需在可被识别的平面上（地面/桌面），点放在同一平面误差小。
- **估算模式**是纯视觉估算：
  - 假设地面水平、相机高度已知、视场角已知；
  - 相机需**向下**对准地面（俯仰角 |β|<90°），否则拒绝测量；
  - 物体应在地面上、靠近画面中心拍摄，离中心越远透视误差越大；
  - **务必用已知长度校准视场角**，否则仅依赖默认 60° 估计，误差可能较大。
- 摄像头视场角因机型不同，默认值与实际可能有偏差，这是估算模式最主要的误差来源。

## 技术栈与结构

```
measure-cam/
├─ index.html            主页面
├─ manifest.webmanifest  PWA 清单（可安装）
├─ sw.js                 Service Worker（离线缓存）
├─ css/style.css         移动端深色 UI
├─ js/
│  ├─ three.min.js       three.js r128（AR 叠加渲染，已本地打包，离线可用）
│  ├─ ar-mode.js         WebXR AR 测量（命中测试 + 锚点/线段渲染）
│  ├─ estimate-mode.js   设备方向反投影估算（核心数学）
│  └─ app.js             主控制器（UI 绑定、测量计算、单位、历史）
├─ icons/                App 图标（192/512 + 生成脚本）
├─ test-estimate.js      估算数学单元测试（node）
└─ check_ids.py          JS/HTML id 交叉校验
```
